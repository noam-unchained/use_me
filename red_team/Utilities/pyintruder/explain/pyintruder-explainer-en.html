PyIntruder

Burp's Intruder — without the wait.

Burp Suite Community throttles Intruder on purpose, to roughly one request per second. PyIntruder does the exact same job — firing hundreds of requests in parallel — and opens a report you can filter like the Intruder window.

what it is

What it does

It's an HTTP fuzzer: paste a raw request (just like copying from Repeater), mark where to attack, choose a payload list, and the tool fires every variation fast and shows you what stood out — which guess returned a different response. Same idea as Intruder, without the free-version speed cap.

workflow

How you use it

1

Paste a request

Copy the raw request from Burp and paste it. The tool figures out method, host, cookies and body on its own.

2

Confirm the marks

It auto-marks parameter values (e.g. mfa-code=§1426§) and asks: accept, or mark manually?

3

Pick attack & payloads

sniper / cluster and friends, then a number range (0000–9999), a wordlist, or an inline list.

4

Fire in parallel

Set how many run at once (default 15) and it goes async. You can also cap the rate.

5

Filter the report

An interactive HTML file opens — filter, sort, and click any row to see the full request & response.

pyintruder
$ pip install 'httpx[http2]'
$ python3 pyintruder.py

# paste the request, mark the spot, pick payloads…
[*] Firing 10000 requests (concurrency=15)...
  sent 10000/10000

attack types

Four attack types

sniper

One list, one marked spot at a time. The classic — a code, username, id.

battering ram

One list, the same value placed in every spot at once.

pitchfork

A list per spot, in parallel — known user+pass pairs.

cluster bomb

A list per spot, every combination — user × password spraying.

results view

The interactive report

  • →
    Search inside responses. "Show only responses that do NOT contain wrong" — and the winner stands alone.
  • →
    Click a row. A side panel shows the exact request that was sent and the full response — a mini Repeater.
  • →
    Anomalies only. Highlights any response that differs from the baseline (status/length) — success jumps out.
  • →
    Sort by click. Click a column (e.g. Length) to sort asc/desc with a direction arrow.
  • →
    Auto re-login. For sites that log you out mid-attack — including CSRF-token extraction via {{CSRF}}.

get started

Running in 30 seconds

You only need Python 3.9+. Install one dependency, run it, and it walks you through step by step:

zsh
$ pip install 'httpx[http2]'
$ python3 pyintruder.py
