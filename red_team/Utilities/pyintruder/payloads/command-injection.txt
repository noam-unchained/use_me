# ==================================================================
#  COMMAND INJECTION PAYLOADS (single file)
#  One payload per line. "#" lines are comments (pyintruder skips them).
#  Detection (best canary of all): the section-0 payloads run `echo xq9z`.
#  Set grep to  xq9z  — if it appears in the response, your command executed.
#  Blind: the time payloads HANG ~5s; the OOB payloads call back to your server.
#  '&' and '>&' are written as %26 so they transmit raw (server decodes them).
# ==================================================================
