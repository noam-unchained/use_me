# ==================================================================
#  XXE PAYLOADS — XML External Entity (single file)
#  One payload per line (whole XML on one line). "#" = comment (skipped).
#  IMPORTANT: XXE goes in an XML BODY (Content-Type: application/xml), NOT a
#  form/query param. In an XML body the '&' of '&x;' is fine — mark the body and
#  replace it with one of these. Detection (canary): set grep to  root:x:0:0
#  (in-band file read) or watch your OOB listener (blind). Replace your-ip.
# ==================================================================
